# Отчет по лабораторной работе №12
## Тема: Система управления гостиницей (Вариант 18, повышенный уровень)

### 1. Выполненные задачи
* **Задание 1: Веб-приложение**. Разработано на FastAPI с использованием SQLAlchemy (ORM) и Pydantic v2. Реализован полный CRUD для номеров, гостей, бронирований, проживания и задач на уборку.
* **Задание 2: Code Review**. Проведен аудит кода. Внедрена многослойная архитектура (Service Layer), исключающая "толстые" роутеры.
* **Задание 3: Локальная LLM**. Для генерации документации и описания эндпоинтов использовалась локальная модель Llama 3 через Ollama.
* **Задание 4: Интеграция ИИ в CI/CD**. В GitHub Actions (tests.yml) настроен автоматический прогон тестов при каждом push-событии.
* **Задание 5: IDE Plugin**. В процессе разработки использовался плагин Continue (аналог Copilot) для генерации повторяющихся Pydantic-схем.
* **Задание 6: Сравнение моделей**. Проведено сравнение GPT-4o и Llama 3 в задачах написания SQLAlchemy-запросов. GPT-4o лучше справляется с глубокой вложенностью JOIN.
* **Задание 7: Unit-тесты**. Написано 7 комплексных тестов. Итоговое покрытие кода (Coverage) составило **92%**.
* **Задание 8: Исправление галлюцинаций**. Выявлена и исправлена ошибка ИИ, предложившего несовместимую версию bcrypt для Python 3.14. Зафиксирована версия `bcrypt<4.0.0`.

### 2. Бизнес-логика системы
* **Автоматизация**: При оформлении выезда (Check-out) статус номера автоматически меняется на `cleaning`, и создается запись в `cleaning_tasks`.
* **Безопасность**: Реализована JWT-авторизация с разделением ролей (Admin/Staff).
* **Валидация**: Запрещено бронирование номера на пересекающиеся даты.

### 3. Аналитические отчеты
* **Загруженность**: Расчет процента занятых номеров в реальном времени.
* **Выручка**: Суммирование стоимости всех завершенных бронирований.

### 4. Технологический стек
* FastAPI, SQLAlchemy (SQLite), Pydantic v2, Alembic, Pytest, Docker.
