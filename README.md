### Описание проекта
Проект представляет собой Backend-систему для автоматизации бизнес-процессов гостиницы. Включает в себя управление номерным фондом, систему бронирования, контроль заезда/выезда гостей и автоматическое формирование задач на уборку номеров.

### Ключевые особенности
* **Архитектура:** Многослойная (Service Layer), разделяющая бизнес-логику и API-эндпоинты.
* **Безопасность:** JWT-авторизация с разделением ролей (Admin/Staff).
* **Качество кода:** Покрытие unit-тестами составляет **92%**.
* **AI-Native разработка:** Проект реализован с применением современных ИИ-инструментов (vibe coding workflow). 
* **Инфраструктура:** Полная поддержка Docker и автоматические миграции через Alembic.

### Технологический стек
* **FastAPI** — веб-фреймворк.
* **SQLAlchemy** — ORM для работы с базой данных (SQLite).
* **Pydantic v2** — валидация данных.
* **Pytest & Coverage** — тестирование.
* **GitHub Actions** — CI/CD пайплайн.

### Инструкция по запуску
1. Установите зависимости: `pip install -r requirements.txt`
2. Примените миграции: `alembic upgrade head`
3. Создайте администратора: `python create_admin.py`
4. Запустите сервер: `uvicorn app.main:app --reload`
5. Swagger UI доступен по адресу: `http://127.0.0.1:8000/docs`
